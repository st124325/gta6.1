# GTA V Web Edition (MVP) 🚗💨

Полноценная 3D игра-песочница в стиле GTA 5, работающая прямо в браузере на базе **Three.js** и физического движка **Cannon-es**.

---

## 🎮 Возможности (Features)

1. **Персонаж (Пешком):**
   - 3D-модель персонажа в стильной кожаной куртке и джинсах.
   - Процедурные анимации ходьбы, бега (спринт), покачивания рук и прыжка.
   - Управление от 3-го лица с плавной камерой и захватом мыши (Pointer Lock).
   - Интерактивная посадка и высадка из любого автомобиля по клавише **[F]**.

2. **Транспорт (Автомобили & Физика):**
   - **4 типа машин с уникальными характеристиками и моделями:**
     - **Pegassi Reaper** (Красный Суперкар): сверхбыстрый, аэродинамичный спойлер, сплиттер, высокая скорость.
     - **Vapid Dominator** (Синий Маслкар): агрессивный воздухозаборник на капоте, гоночные полосы, мощный дрифт.
     - **Canis Kamacho 4x4** (Внедорожник): высокий клиренс, силовой трубчатый каркас, огромные колёса, прыжки на трамплинах.
     - **Police Cruiser** (Полицейский перехватчик): раскраска шерифа, стробоскопы и красно-синяя мигалка на крыше.
   - Физика подвески, крутящий момент, дрифт и торможение с ручником (**[Пробел]**).
   - **Нитро-ускорение (Nitro Boost)** на **[Shift]** с динамическим пламенем из выхлопных труб.
   - Рабочие фары с реальным освещением дороги (**[L]**).
   - Клаксон (**[H]**).
   - Переворот автомобиля на колёса (**[R]**), если машина перевернулась при трюке.

3. **Открытый город (Open World & Stunts):**
   - Дорожная сеть с разметкой, тротуарами и пешеходными переходами.
   - Разнообразные небоскрёбы и здания с неоновыми вывесками (*"Maze Bank"*, *"Los Santos Customs"*, *"Burger Shot"*, *"Ammu-Nation"* и др.).
   - Вертолётные площадки на крышах небоскрёбов.
   - **Мега-трамплины и рампы для трюков:** гигантские рампы для прыжков на скорости через кварталы!
   - Разрушаемые дорожные конусы и гидранты с физикой.
   - Пальмы и уличные фонари.

4. **GTA HUD & Интерфейс:**
   - **Круглый радар-миникарта** в левом нижнем углу: отображает сетку дорог, положение игрока, стрелку направления взгляда, иконки машин и трамплинов, а также шкалы здоровья (зелёная) и брони/нитро (синяя).
   - **Спидометр** в правом нижнем углу: цифровая скорость (КМ/Ч), номер передачи (1–5, R), полоска нитро.
   - **Звёзды розыска (Wanted Stars):** 5 звёзд в правом верхнем углу.
   - Экран **"WASTED"**.
   - Переключение времени суток на **[T]** (Солнечный день, Закатный час, Неоновая ночь).
   - Переключение радиостанций на **[Q]**.
   - Переключение ракурсов камеры на **[C]**.

5. **Звуковая система (Web Audio API):**
   - 100% процедурные звуки без необходимости скачивания тяжёлых mp3:
     - Синтез рычащего мотора V8 с изменением оборотов и переключением передач.
     - Визг покрышек при заносе / дрифте.
     - Клаксон.
     - Звук удара при столкновениях.
     - Шаги и прыжки персонажа.
     - Полицейская сирена.
     - Встроенное радио (Synthwave / West Coast Beats).

## 🚀 Как запустить игру

### Способ 1 (Самый быстрый)
В терминале перейдите в папку `game` и запустите:
```bash
cd /home/artem/game
./start.sh
```
*Скрипт автоматически поднимет локальный веб-сервер и откроет игру в вашем браузере по адресу `http://localhost:8080`.*

### Способ 2 (Через npm)
```bash
npm start
```

### Способ 3 (Через Python вручную)
```bash
python3 -m http.server 8080
```
И откройте в браузере: `http://localhost:8080`

## ⌨️ Управление

| Клавиша | Пешком | За рулём |
|---|---|---|
| **W, A, S, D** | Перемещение | Газ / Тормоз / Руль |
| **Shift** | Спринт (быстрый бег) | **Нитро (Nitro Boost)** |
| **Пробел** | **Прыжок** | **Ручник (Дрифт)** |
| **F** / **E** | **Сесть в ближайшую машину** | **Выйти из машины** |
| **R** | — | **Перевернуть авто на колёса** |
| **C** | Сменить дистанцию камеры | Сменить дистанцию камеры |
| **L** | — | Вкл/выкл фары |
| **H** | — | Сигнал клаксона |
| **Q** | Переключить радио | Переключить радио |
| **T** | Сменить время суток | Сменить время суток |
| **Мышь** | Обзор камерой | Обзор камерой |
| **Клик** | Захват курсора (Pointer Lock) | Захват курсора |
| **Esc** | Освободить курсор | Освободить курсор |
